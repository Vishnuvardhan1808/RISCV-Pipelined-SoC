# RISCV-Pipelined-SoC
This repository contains the Verilog RTL implementation of a 32-bit, 5-stage pipelined RISC-V System-on-Chip (SoC). The design advances beyond a single-cycle architecture by integrating a complete memory hierarchy, cycle-accurate hazard management, and an AXI4 memory controller interface to manage memory access latencies seamlessly.
